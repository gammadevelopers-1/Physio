# PhysioGuidance

Nationally aligned healthcare eLearning & training platform

## Project Structure

```
/
├── frontend/     # Next.js frontend application
├── backend/      # Backend API (TBD)
└── README.md
```

## Frontend

The frontend is built with Next.js 14, React, and Tailwind CSS.

### Setup

```bash
cd frontend
npm install
npm run dev
```

### Tech Stack
- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- TypeScript
